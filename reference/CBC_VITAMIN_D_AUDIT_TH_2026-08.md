# Clinical audit — Eosinophil และ Vitamin D

Clinical review date: 2026-08-22

เอกสารนี้เป็น correction overlay สำหรับข้อความใน `reference/คำแนะนำผลตรวจสุขภาพ_ภาษาไทย.md` ที่เกี่ยวกับ Eosinophil และ Vitamin D

## 1) CBC-TH-038 ถึง CBC-TH-044 — Eosinophil

### ปัญหา

ข้อความเดิมหลายรายการใช้ `700 cells/mm^3` เป็นเส้นแบ่งสำคัญ และบางรายการชวนไปสู่การรักษาพยาธิจาก eosinophilia โดยตรง ทั้งที่การประเมินควรใช้ Absolute eosinophil count (AEC) และพิจารณาสาเหตุตามประวัติ/อาการ

โดยทั่วไป AEC >500 cells/µL ถือว่าเป็น eosinophilia และแบ่งโดยประมาณเป็น:

- 500–1,500 cells/µL: mild eosinophilia
- 1,500–5,000 cells/µL: moderate eosinophilia
- >5,000 cells/µL: severe eosinophilia

### Replacement wording — mild eosinophilia

```text
พบจำนวนเม็ดเลือดขาวชนิด Eosinophil สูงกว่าปกติเล็กน้อย (Mild eosinophilia) ซึ่งอาจสัมพันธ์กับโรคภูมิแพ้ หอบหืด ผื่นแพ้ ยาหรืออาหารเสริมบางชนิด และการติดเชื้อพยาธิบางชนิด ควรพิจารณาร่วมกับอาการและประวัติความเสี่ยง หากไม่มีอาการผิดปกติรุนแรง แนะนำตรวจ CBC ติดตามอีกประมาณ 1-3 เดือน หากยังสูงต่อเนื่อง สูงมากขึ้น หรือมีอาการผิดปกติ ควรปรึกษาแพทย์เพื่อตรวจหาสาเหตุเพิ่มเติม
```

### เมื่อมีประวัติเสี่ยงพยาธิ

```text
หากมีประวัติรับประทานอาหารสุกๆ ดิบๆ เดินเท้าเปล่าบนดินชื้น หรือมีความเสี่ยงต่อการติดเชื้อพยาธิ ควรแจ้งแพทย์เพื่อพิจารณาตรวจเพิ่มเติมตามชนิดพยาธิที่สงสัย ไม่ควรแนะนำยาถ่ายพยาธิจากค่า Eosinophil สูงเพียงอย่างเดียวโดยไม่มีการประเมินความเสี่ยงและข้อห้ามของยา
```

### Red flags

หาก AEC >=1,500 cells/µL ต่อเนื่อง หรือมีไข้ น้ำหนักลด ต่อมน้ำเหลืองโต หอบเหนื่อยมาก ผื่นรุนแรง อาการทางหัวใจ/ระบบประสาท หรือความผิดปกติของ CBC ชนิดอื่นร่วมด้วย ควรประเมินโดยแพทย์เร็วขึ้น

## 2) VIT-TH-002, VIT-TH-003 และคำแนะนำ Vitamin D ที่ใช้ threshold แบบตายตัว

### ปัญหา

ข้อความเดิมใช้คำว่า "วิตามินดีต่ำกว่าปกติมาก" แบบกว้าง และแนะนำให้สัมผัสแดดโดยใช้ครีมกันแดดไม่เกิน SPF 8 รวมถึงบางข้อความกำหนดขนาด Vitamin D/Calcium แบบตายตัว ปัจจุบัน Endocrine Society 2024 ระบุว่ายังไม่มี 25(OH)D threshold เดียวที่พิสูจน์ว่าเป็นระดับเป้าหมาย optimal สำหรับการป้องกันโรคในคนสุขภาพดี และไม่แนะนำ routine testing หรือการไล่ระดับ serum vitamin D เพื่อกำหนดการเสริมในคนสุขภาพดีทั่วไป

### Replacement wording — ต่ำกว่าช่วงอ้างอิงของห้องปฏิบัติการเล็กน้อย

```text
ระดับ 25-OH Vitamin D ต่ำกว่าช่วงอ้างอิงของห้องปฏิบัติการเล็กน้อย แนะนำรับประทานอาหารที่มีวิตามินดีเป็นประจำ เช่น ปลาที่มีไขมันสูง ไข่ นม หรือผลิตภัณฑ์ที่เสริมวิตามินดี และเห็ดบางชนิด ร่วมกับการออกกำลังกายและดูแลสุขภาพกระดูกตามปกติ ไม่จำเป็นต้องลดการใช้ครีมกันแดดหรือจงใจรับรังสี UV มากขึ้นเพื่อเพิ่มวิตามินดี หากเป็นคนสุขภาพดีทั่วไปไม่ควรเพิ่มขนาด Vitamin D supplement จากผลตรวจเพียงค่าเดียวโดยไม่ได้พิจารณาอายุ อาหาร โรคกระดูก โรคไต/ตับ การดูดซึมผิดปกติ และปัจจัยเสี่ยงอื่นร่วมด้วย
```

### เมื่อควรพบแพทย์เพื่อพิจารณาการรักษาเฉพาะ

หากมี osteoporosis/osteomalacia, fragility fracture, hypocalcemia, malabsorption, chronic kidney/liver disease, ใช้ยาที่มีผลต่อ vitamin D metabolism หรือมีเหตุผลทางคลินิกอื่นสำหรับการตรวจ 25(OH)D ควรให้แพทย์พิจารณาเป้าหมายและขนาดการรักษาตามบริบท ไม่ใช้ข้อความ general health-check แทน

## Primary references

- Endocrine Society. Vitamin D for the Prevention of Disease Clinical Practice Guideline, 2024.
- Merck Manual Professional Edition. Eosinophilia, reviewed/revised 2026.

## Operational rule

สำหรับ health check ทั่วไป ให้ใช้ AEC มากกว่าเปอร์เซ็นต์ Eosinophil เพียงอย่างเดียว และใช้คำว่า mild eosinophilia เมื่อ AEC 500–1,500 cells/µL ส่วน Vitamin D ให้สะท้อนช่วงอ้างอิงของแล็บโดยหลีกเลี่ยงคำว่า "ต่ำมาก" หรือการสั่ง supplement แบบตายตัว หากไม่มีบริบทโรคกระดูก/โรคร่วมที่ชัดเจน
